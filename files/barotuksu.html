1계산할 달과 방학

방학이 이번 달에 걸칠 때만 적으세요. 아래 달력에서 날짜를 누르면 학기 중 ↔ 방학 중을 바꿀 수 있습니다(주휴일 조정).

2나이스 파일 넣기

나이스 파일 이렇게 받으세요

1교육공무직등인사 › 인사기록관리 › 인사기록(인사권한)에서 사람 조회

2오른쪽 위 출력 단추 누르기

3[인사기록카드 출력] 창에서 ☑ 근무사항만 체크 → 출력

4출력 화면에서 엑셀(xlsx)로 저장 → 그 파일을 끌어다 놓기

인사기록카드 출력
☑ 근무사항☐ 인적사항☐ 계약사항☐ 인사발령☐ 채용전경력☐ 휴직사항
전체선택출력닫기

3사람별 확인 · 결과

빨간 칸(직종 구분 · 주 소정근로시간 · 가족수당 등)은 나이스 파일만으로 알 수 없으니 직접 확인하고 채우세요. 고치면 결과가 바로 바뀝니다.

아직 사람이 없습니다. 위에 나이스 파일을 넣어 주세요.
